# Handover notes

## What this is
A complete data quality and PII pipeline built for DEM11 (Data Governance,
Quality, and Security). Start with `README.md`, then `docs/pipeline_design.md`.

## Quick start
```bash
pip install -r requirements.txt
export PII_PSEUDONYM_SALT="$(openssl rand -hex 32)"
python scripts/run_pipeline.py
python -m pytest tests/ -q
```

## Read the code in this order
1. `config/schema.yaml`            — the contract; everything else obeys it
2. `src/ingestion/files.py`        — why raw data is loaded as text
3. `src/profiling/profiler.py`     — describing what IS there
4. `src/pii/detector.py`           — three-signal PII detection
5. `src/transformations/validation.py` — the two-contract severity engine
6. `src/transformations/cleaning.py`   — every change is logged
7. `src/pii/masker.py`             — masking + k-anonymity measurement
8. `src/pipelines/dq_pipeline.py`  — orchestration, gates, lineage

## Before submitting
- [ ] Rewrite `reports/reflection.md` in your own voice. Keep the numbers and
      arguments; change the sentences. It is the one deliverable that should
      sound like you.
- [ ] Re-run the pipeline so all reports carry the same run_id.
- [ ] If the course supplies its own `customers_raw.csv`, drop it into
      `data/raw/` (overwriting the synthetic file) and re-run. Expect some
      thresholds in `config/schema.yaml` to need tuning to that file.

## Known limitations (deliberate, documented in the reflection)
- Salt falls back to an insecure development value if the env var is unset.
- No retention policy on `data/raw/`.
- Quarantined rows have no owner or SLA.
- Run metrics are not stored over time, so trends cannot be alerted on.
- Duplicate people (same name + DOB, different id) are detected but not merged;
  that needs fuzzy record linkage.

## Data warning
`data/raw/customers_raw.csv` is SYNTHETIC — generated by
`scripts/generate_raw_data.py`, safe to share. If you replace it with real data,
`.gitignore` already excludes `data/raw/`, `data/quarantine/`, `reports/` and
`reports/masked_sample.txt`. Keep it that way.
